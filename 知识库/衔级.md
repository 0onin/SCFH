联邦星际军衔体系，为荣誉、权限等级，非职位绑定

# 联邦元帅
最高荣誉军衔，全联邦常设员额不超过 7 人，仅授予对联邦疆域、存续有决定性贡献者。 
仅代表联邦最高军事荣誉、最高军事法庭豁免权、最高机密阅览权限、星域战略投票权，**不绑定任何指挥职位**，可无实际职务、可临时赋权、可终身荣衔。
# 统将
战略级军衔，联邦武装力量顶层衔级，员额严格受限。 
准元帅
代表星域级战略决策权限、跨战区协调权、最高作战预案签署权，**不绑定固定舰队或战区**，可担任虚职、顾问、军事观察员、战略督导官。
# 大将
舰队顶层军衔，战区最高基准衔级。 
代表全域作战资历、舰队集群指挥资格、星域驻防授权资质，**可指挥任何规模舰队，也可无指挥权仅担任荣誉职务**。
# 上将
将官顶层，主力舰队基准衔级。 
通常具有舰队指挥资质、星域驻防资格、高级军事仲裁权，与舰队规模、职位高低无强制对应。
# 中将
将官核心层。 
通常具有舰队独立指挥资格、星域前线决策权、大型作战单位管辖资质，可前线执掌指挥权，也可后方担任行政、科研、督导职务。
# 少将
将官基础层，战队基准衔级。
代表单旗舰编队指挥资格、特种作战授权、前线战略执行权，是将官与校官的核心分界衔级。
# 准将
将官预备层，校级顶端过渡衔级。 
代表独立作战编队指挥资格、前线临时授权资格，是唯一可在尉官、校级、将官职位间灵活任职的过渡军衔。

# 上校
校官顶层，联邦标准核心衔级。 
星际舰队最通用的骨干基准军衔。
# 中校
校官中层。
通常具有总队指挥资质、部门主官资格、前线作战执行权，可任职指挥、技术、情报、后勤全序列岗位。
# 少校
校官基础层，作战舰 / 核心部门基准衔级。 
通常具有战舰指挥资格、核心部门主管资质、分舰队执行负责人资格，覆盖舰队全职能岗位。

---
# 上尉
尉官顶层，基层指挥核心衔级。
通常具有中队指挥资格。
# 中尉
尉官中层，标准军官基准衔级。 联邦军官入职后的标准稳定衔级，代表岗位全权负责资格、独立任务执行权，覆盖全舰所有军官岗位。
# 少尉
尉官基础层，军官入门衔级。 联邦正式军官最低衔级，代表基础指挥授权、岗位独立操作权、任务执行资格，无指挥权下限限制。
