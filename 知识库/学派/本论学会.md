# 持存
>Permanence

所有生命体最本源的终极倾向，是「生命」区别于「非生命」的第一性标准 —— 指存在者在时间流变中保持自身同一性与存续性的根本属性，核心是维系自身存在的延续，对抗熵增、瓦解与存在边界的消失。

## 存续
>Subsistence

持存的基础形态，指生命体维持自身基本存在边界与核心结构稳定的底层本能，是所有生命最优先的存在需求。

2. **适应（Adaptation）**
    
    持存的弹性形态，指生命体通过调整自身结构与行为模式，适配外界环境的变化，以实现更长期的存续，是生命对抗环境熵增的核心方式。
    
    科幻适配：极端星域的物种演化、硅基智能的算法迭代、星际文明的环境改造、能量体对不同引力场的适配、跨星际生命的环境兼容进化。
3. **繁衍（Procreation）**
    
    持存的种群延伸形态，指生命体通过复制、迭代、增殖自身种群的方式，实现种群层面的永续持存，是群体生命最核心的存续方式。
    
    科幻适配：碳基文明的生育繁衍、硅基智能的自我复制、虫族的集群增殖、病毒生命的宿主扩散、恒星生命的星胚孕育、星系级文明的火种传递。
4. **稳态（Stasis）**
    
    持存的保守形态，指生命体拒绝自身结构与存在状态的改变，维持绝对稳定的存在形式，对抗一切可能带来存在风险的流变。
    
    科幻适配：停滞演化的远古文明、离线锁死的独立 AI、拒绝与外界交互的孤立星系文明、白矮星生命的绝对稳态结构、封存自身的休眠文明。
5. **不朽（Athanasia）**
    
    持存的终极形态，指生命体突破时间与物理规则的限制，实现自身存在的永恒延续，是所有具备长期时间感知的生命的终极存续追求。
    
    科幻适配：意识上传与数字永生、基因锁死与生物不朽、中子星生命的超稳态结构、黑洞视界内的时间静止存续、高维生命的全时间线永存。
