# 帝国议院

概述
帝国议院为埃维斯联邦政府的上议院与最高审议机关，主要承担对联邦议院重要决议的最终审批、国家长期政策的把关与帝国战略性安全事项的终局审议职能。议院的设置旨在于维持帝国核心的最终主权，同时为被整合地区提供制度化的参与通道，形成稳定的统御与参与并存的治理格局。

历史沿革
帝国议院源于帝国扩张早期的制度调整。随着疆域扩大与被征服地区管理需求的转变，埃维斯中央为降低统治成本与防止叛乱，逐步引入代表性机构，将部分地方精英吸纳入决策体系。经过多次演变与制度化，帝国议院最终确立为具否决与终审权的上议院，成为联邦政府制衡结构的核心。

职能与权限
- 终审权：对联邦议院通过的重大法律、宪制性修改、重要外交与军事决议享有最终审批或否决权。
- 宪政监督：负责监督联邦政府与下属行政机构的合规性与长期政策方向，必要时发起调查与听证。
- 战略审议：对涉及帝国安全、核心军事部署、跨级文明接触与极端科技应用的议案进行秘密或特权审议。
- 任免与赦免建议：对高级官员、司法人事及部分重要职务具有建议或确认权，参与重大赦免与特别授权的审批流程。

组织结构
帝国议院由若干常设机构与议员会议组成，设有若干委员会以分工处理不同事务：
- 检查委员会：负责监督政府运行与廉政审查，设监察司、管理局等办事机构；
- 军事与安全委员会（与帝国军事委员会并行）：处理涉及终局国防策略与重大武力动用的审议事项；
- 审议委员会：对法律草案与长期政策进行文本审查与修改建议；
- 外交与文明接触委员会：审查跨文明交流、条约与特殊接触许可。

会议形式
议院定期召开全体大会以审议重要事项，并可在紧急情形下召开闭门紧急会议（帝事会议）。多数议案需通过规定票数方能送交批准或否决；涉及国家安全与军事事项的审议常在特权级别下进行，仅限特定议员与受授权代表参与。

议员构成与选拔
议员来源多样化但带有明显的帝国色彩：核心议席通常由埃维斯家族主要成员、世袭贵族与帝国内部重要宗教或机构代表占据；地方议席则由各被整合地区的重要领袖或代表担任，其名额与权重由历史条约与帝国内部协议确定。议员的选拔兼具指派与地区遴选机制：
- 指派席位：由帝国中心直接委任或保留，负责维护帝国核心利益；
- 地方代表席位：由地区内部精英、协商会议或文化/利益团体推荐产生，作为帝国向导入融合渠道的制度化体现。

议员权利与义务
议员享有提出议案、召集听证、参与委员会审查与对联邦重大决议行使否决或审批的权利。议员亦需承担保密义务、出席义务与对所属地区的制度性责任。对因渎职或叛国的议员，议院拥有弹劾与罢免程序。

制衡与互动
帝国议院与联邦议院之间形成以终审权与执行权为核心的制衡关系：联邦议院负责日常立法与行政执行，帝国议院则在政治的上层进行价值与战略把关。帝国军事委员会与议院军事与安全委员会在实际权力中保持高度互动，确保国防决策既受民政建议又不脱离帝国核心控制。

特权与机密性
鉴于帝国议院涉及大量国家机密与战略性议题，议院运作设有特权级审议程序与保密条款。若干议题仅在受限的议员子集间以密会形式处理，相关记录通常被列为帝国机密，公开程度受严格限制。

文化与礼仪
帝国议院在政治外亦承担象征性与礼仪性职能：议院大会常伴随传统仪式与政治表态，作为帝国统一性与连续性的象征。议员之间的互动受传统礼制、家族礼仪与政治惯例影响较深，这些文化要素在维系帝国统治合法性中发挥重要作用。

监督、问责与改革通道
虽为上议院，帝国议院并非绝对不受约束。内部设有监督机制与伦理委员会，必要时可对议员与机构提出审查。历史上，为适应帝国扩张与内部压力，议院曾多次进行程序性改革以调整席位分配与审议流程。

与地方关系
帝国议院既是中央权威的代表，也是整合被征服地区精英的话语平台。通过制度化的代表参与与议席分配，帝国议院在政治上提供了地方利益表达的渠道，从而降低了直接军事统治的成本并提高了统治的合法性。
